# Project Overview

BrightTV is a subscription-based streaming platform aiming to grow its customer base.

The CEO requested an analytical report that investigates:

* Subscriber demographics
* Viewing behaviour
* Consumption trends
* Peak viewing periods
* Customer engagement
* Business opportunities for increasing subscriptions

This project demonstrates a complete analytics workflow from raw Excel data to executive-level business recommendations.

# Business Problem

BrightTV wants to increase subscriptions and improve customer engagement.

Using subscriber profile information and viewership session data, this project identifies:

* User trends
* Usage trends
* Factors influencing consumption
* High-performing content
* Low-performing periods
* Growth opportunities

# Business Objectives

* Analyse subscriber demographics

* Analyse viewing behaviour

* Identify peak viewing periods

* Discover factors influencing content consumption

* Recommend content for low-consumption periods

* Develop strategies for increasing BrightTV subscriptions
